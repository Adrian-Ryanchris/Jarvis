Jarvis privacy policy

Last updated 17 November 2026

Jarvis is a personal application used by its developer, Adrian Arokiyaraj, on their own computer. It has no other users. This policy describes what it does with Google account data.

What data Jarvis accesses

When the owner connects their Google account, Jarvis can use these permissions, each of which the owner may decline:

  • Calendar events: read events, and create, change or delete them.
  • Read email: search and read messages.
  • Draft and send email: save drafts and send messages.

Jarvis does not request any other Google permission, and it cannot delete or archive email.

How the data is used

Data is used only to carry out what the owner asks for, for example to answer "what is on my calendar today?" or to draft a reply. Calendar changes and emails are made or sent only after the owner approves each one.

Where the data is stored

Jarvis runs on the owner's computer. The Google sign-in token is stored in a file on that computer, readable only by the owner's account. Calendar and email content is read when needed and is not copied into any database or log kept by Jarvis. Jarvis has no server of its own and does not send Google data to its developer.

AI language models

To answer a request, the relevant calendar or email text is sent for that one request to the AI model provider the owner has configured (currently Groq or Google Gemini), or to a model running locally on the owner's computer. The owner can switch a setting so that only the local model is ever used. Google user data is not used to train any model by Jarvis, and it is not sold or shared with anyone else, apart from the model provider in the way just described, solely to produce the answer.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. No humans read the data except as the owner does themselves.

Deleting data and withdrawing access

The owner can disconnect at any time in Jarvis (Settings, Google, Disconnect), which revokes access at Google and deletes the stored token. Access can also be removed at myaccount.google.com/permissions.
